# B-roll library for @ihackgrowth

Drop video clips into this folder (any file names). Each reel run describes new clips automatically and the editor uses
them where they fit the script. A clip rests for 3 reels after it's used.

**Upload:** on GitHub open this folder → *Add file* → *Upload files* → drag the clips → *Commit changes*.
(Max 25 MB per file on the web uploader; Flow's 8-second clips are well under that.)

## Flow settings
- Model: Veo (best quality available to you) · **Landscape 16:9** · 1 output per prompt is enough
- Text-to-video. Download the 720p or 1080p MP4.
- Skip a clip if it has warped hands/faces, readable text, or a logo — those look fake on a reel.

## Prompts (copy one at a time; the style line is already included in each)

Every prompt ends with the same style so the library looks like one series:
*"Cinematic, dark moody room, warm amber key light with cool blue screen glow, shallow depth of field, 35mm film look, slow
camera push-in. No text, no logos, no readable screen content."*
